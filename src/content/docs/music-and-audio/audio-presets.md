## The `{filter}` Parser

Applies high-performance digital signal processing (DSP) presets:

```tagscript
{filter:nightcore}
{filter:8d}
{filter:bass}
{filter:clear} <!-- Resets all filters to normal -->
```

---

## All 30 Built-in Presets

| Preset | Description |
| :--- | :--- |
| `8d` | 360-degree rotational panning audio (best with headphones) |
| `bass` / `bassboost` | Heavy low-end frequency boost |
| `nightcore` | Increased speed (1.25x) and higher pitch (1.3x) |
| `vaporwave` | Nostalgic slowed speed (0.8x) and pitch |
| `pop` | Tuned mid-range equalizer for vocal clarity |
| `soft` | Attenuated highs and gentle acoustic sound |
| `slow` / `speed` | Custom timescale velocity adjusters |
| `karaoke` | Vocal cancellation filter |
| `underwater` | Submerged low-pass acoustic profile |
| `tremolo` | Rapid volume modulation oscillator |
| `vibrato` | Rapid pitch modulation oscillator |
| `distortion` | Harmonic overdrive saturation |
| `clear` | Completely clears all active filters and equalizers |

*(Full list includes: `party`, `earrape`, `electronic`, `radio`, `treblebass`, `china`, `chipmunk`, `darthvader`, `daycore`, `doubletime`, `pitch`, `rate`, `glitch`, `robot`, `widen`)*
